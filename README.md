# FitLog

FitLog is a dark-themed workout library app. Browse a collection of lifts, view their details, and build a daily plan with a limit of five workouts.

## Technologies Used

- Next.js
- Next.js App Router
- React
- TypeScript
- Tailwind CSS
- react-hot-toast
- lucide-react

## Key Features

1. Workout library with a responsive card grid and a loading state while data is fetched.
2. Workout details page with specs, instructions, and action buttons.
3. Add workouts to Today's Plan (max 5) or save them for later, with toast notifications.
4. My Plan page with a live dashboard (exercises, minutes, calories), tabs, sorting, Mark as Done, and remove.
5. Plan and saved data persist in localStorage, and the navbar badges update live.
